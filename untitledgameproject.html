Untitled Game Project (2025)

An exploration of game development and the skills required

I started this project as a way to keep me entertained while applying for jobs, expanding my skillset in the process. While the full fledged idea of the game and the gameplay loop have yet to been figured out, I have learned a lot so far in the development. These skills include creating low poly assets, texturing within blender, creating a third person controller within Unity and implementing basic game features such as chopping down trees.

Work on Untitled Game Project

3D Art and Texturing

The very first thing I tackled when beginning this process was to create the character. As I am aiming for a more stylized look within the game, I settled on a low poly character. After the base model was finished, I added details such as hair, facial hair and clothing. After that, I created more detailed textures for the model. All of this was done within Blender.

After creating the character, I went ahead and made some low poly models of tools that will play a central part in the game. These tools are an axe, a pickaxe, and a shovel. As with the character, all modeling and texturing was made within Blender.

Lastly, I created some models for props within the world. This includes cliffs, a mountain and various types of trees. All of this once again done within Blender. As per the character and the tools, all textures where also created by me within either Blender or Photoshop.

Animation and Game Development

The third person controller was created using the character model and animations for each possible movement direction (left, right, up, down, as well as diagonal movement). Aside from the movement animation, I also created animations for three types of interactions with resources: chopping a tree, mining rocks, and digging dirt. I also created a very basic UI for a toolbar and inventory system, as well as creating the inventory system which allows for stacking of objects and drag/drop functionality.

Environment Design and Shaders

The idea is for the game to take place on an isolated island, with nothing but ocean surrounding it. By combining Unity's terrain tool with the assets I created, I made a raised island with steep cliff edges. All textures for the terrain were also created by me within Photoshop. To create the ocean surrounding the island, I created a URP Shader to simulate water movement and applied this to a plane. To populate the island with trees, I utilized the terrain tools mass place trees function. However, this function does not allow for prefab instances with attached scripts, so I created a new function that takes the placement of the trees made by the terrain tool and simply replaces each tree with the correct tree prefab. In the future I am considering replacing this function entirely with some of the work I did within my master thesis. Lastly I implemented some post processing, as well as Unity's built-in fog system to create more "dreamy" look for the island.
